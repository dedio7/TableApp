📋 1. Introduction

This privacy policy describes how the DailyPulse application (package: com.dedio.dailypulse) handles user data. The app is developed and maintained by an independent developer.

✅ In short: DailyPulse does not collect, transmit, or sell any personally identifiable data. All device data stays local, except for necessary requests for weather and news.

🔒 2. Dati raccolti e utilizzo

DailyPulse non raccoglie dati personali identificativi. L'app richiede determinati permessi Android esclusivamente per fornire le sue funzionalità. Di seguito sono elencati i permessi critici e il relativo utilizzo:

PermessoScopoDati coinvolti
INTERNET
ACCESS_NETWORK_STATE		 Recupero dati meteo dall'API Open-Meteo e feed di notizie RSS Nessun dato utente inviato. Solo richieste in lettura a servizi pubblici.
ACCESS_FINE_LOCATION
ACCESS_COARSE_LOCATION		 Determinare la posizione per le previsioni meteo aggiornate Le coordinate (latitudine e longitudine) vengono rilevate tramite il GPS del dispositivo. Questi dati vengono inviati in modo anonimo all'API Open-Meteo per ottenere il meteo locale. La posizione viene elaborata in modo effimero e non viene mai memorizzata permanentemente.
READ_CALENDAR
WRITE_CALENDAR		 Visualizzare gli eventi del calendario sulla dashboard I dati del calendario restano sul dispositivo e non vengono mai trasmessi all'esterno.

🔒 2. Data collected and usage

DailyPulse does not collect personally identifiable data. The app requests certain Android permissions solely to provide its features. Critical permissions are listed below:

PermissionPurposeData involved
INTERNET
ACCESS_NETWORK_STATE		 Fetch weather data from the Open-Meteo API and RSS news feeds No identifying user data is sent. Read-only requests to public services.
ACCESS_FINE_LOCATION
ACCESS_COARSE_LOCATION		 Determine user location for real-time weather updates Coordinates (latitude and longitude) are retrieved via the device GPS. This data is sent anonymously to the Open-Meteo API to fetch local weather. Location data is processed ephemerally and is never permanently stored.
READ_CALENDAR
WRITE_CALENDAR		 Display calendar events on the dashboard Calendar data stays on-device and is never transmitted externally.

💾 3. Archiviazione dei dati

Tutti i dati dell'app sono memorizzati localmente sul dispositivo dell'utente:

  • Impostazioni dell'app: salvate tramite Android DataStore (solo su dispositivo).
  • Dati meteo: memorizzati temporaneamente nella cache locale per l'utilizzo offline.
ℹ️ Nota sulla Posizione: I dati GPS vengono utilizzati solo nel momento della richiesta meteo. Non teniamo traccia degli spostamenti dell'utente e non memorizziamo alcuno storico delle posizioni.

💾 3. Data storage

All app data is stored locally on the user's device:

  • App settings: saved via Android DataStore (on-device only).
  • Weather data: temporarily cached locally for offline use.
ℹ️ Note on Location: GPS data is used only at the time of the weather request. We do not track user movements and do not store any location history.

🌐 4. Servizi di terze parti

DailyPulse interagisce con i seguenti servizi esterni:

Open-Meteo API

Utilizzata per ottenere dati meteorologici. Open-Meteo è un'API open source che non richiede chiavi API né identificazione dell'utente. Le uniche informazioni inviate sono le coordinate geografiche necessarie per identificare la città e le condizioni meteo.

🔗 Informativa sulla privacy di Open-Meteo: open-meteo.com/en/terms

✅ Nessun tracciamento: L'app non integra SDK di analisi (come Google Analytics), pubblicità o crash reporting di terze parti.

🌐 4. Third-party services

DailyPulse interacts with the following external services:

Open-Meteo API

Used to fetch weather data. Open-Meteo is an open-source API that does not require API keys or user identification. The only information sent is geographic coordinates necessary to identify the city and weather conditions.

🔗 Open-Meteo privacy policy: open-meteo.com/en/terms

✅ No tracking: The app does not integrate any third-party analytics (like Google Analytics), advertising, or crash reporting SDKs.

🚫 5. Condivisione dei dati

DailyPulse non condivide, non vende e non trasferisce alcun dato personale a terze parti. Non esistono account utente né sistemi di profilazione.

🚫 5. Data sharing

DailyPulse does not share, sell, or transfer any personal data to third parties. There are no user accounts or profiling systems.
